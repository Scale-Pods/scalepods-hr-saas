# Razorpay Integration Plan for ScalePods HR SaaS

This document outlines the step-by-step implementation plan for integrating Razorpay Subscriptions into the ScalePods HR SaaS platform, specifically tailored for your app's usage and billing plans.

## 1. Prerequisites (Razorpay Dashboard)
- [ ] Create Subscription Plans in your Razorpay Dashboard corresponding to your paid tiers:
  - **Basic** (10 AI Credits, 500 resumes/month, 5 campaigns)
  - **Growth** (100 AI Credits, Unlimited resumes/month, 25 campaigns)
  - **Enterprise** (Custom/Unlimited volume)
  *(Note: The 'Free' tier doesn't require a Razorpay plan).*
- [ ] Save the Plan IDs generated by Razorpay (e.g., `plan_xxx`).
- [ ] Create a Webhook endpoint (e.g., `https://your-domain.com/api/razorpay/webhook`).
- [ ] Generate a Webhook Secret.
- [ ] Configure Webhook events (`subscription.charged`, `subscription.created`, `subscription.cancelled`, `subscription.halted`, `payment.failed`, `payment.captured`).

## 2. Environment Variables
Add the following to your `apps/web/.env.local` and Vercel environment:
```env
RAZORPAY_KEY_ID="rzp_test_..."
RAZORPAY_KEY_SECRET="your_api_secret"
RAZORPAY_WEBHOOK_SECRET="your_webhook_secret"

# We also expose the key ID to the frontend for initializing checkout
NEXT_PUBLIC_RAZORPAY_KEY_ID="rzp_test_..."
```

## 3. Database Schema Updates (Supabase)
Update your Supabase user/organization table (and `packages/core/src/schemas.ts`) to track subscription and plan status:
- `razorpay_customer_id`: string (nullable)
- `razorpay_subscription_id`: string (nullable)
- `plan`: string (Must match your app's plans: `'free'`, `'basic'`, `'growth'`, `'enterprise'`)
- `subscription_status`: string (e.g., 'ACTIVE', 'PAST_DUE', 'CANCELED')
- `next_billing_date`: timestamp

## 4. Install Razorpay SDK
Install the Razorpay Node SDK in your `apps/web` (or `packages/core`):
```bash
npm install razorpay
```
*(You will also need to load the `https://checkout.razorpay.com/v1/checkout.js` script in your frontend).*

## 5. Backend API Routes (Next.js App Router)
Create the necessary API routes under `apps/web/src/app/api/razorpay/`:

### A. `/api/razorpay/create-subscription` (POST)
- **Purpose**: Called by the frontend when a user selects "Basic", "Growth", or "Enterprise".
- **Logic**:
  1. Authenticate user.
  2. Create a customer in Razorpay (if they don't have a `razorpay_customer_id` yet).
  3. Create a subscription using `razorpay.subscriptions.create({ plan_id, customer_id })` mapped to your specific `plan_id`.
  4. Return the `subscription_id` to the frontend.

### B. `/api/razorpay/webhook` (POST)
- **Purpose**: Called by Razorpay when events happen.
- **Logic**:
  1. Verify the webhook signature using `RAZORPAY_WEBHOOK_SECRET` and the `crypto` library.
  2. Switch based on `event` type:
     - `subscription.charged`: Update Supabase `subscription_status = 'ACTIVE'` and `next_billing_date`.
     - `subscription.cancelled`: Update status to `'CANCELED'`.
  3. Respond with `200 OK` quickly so Razorpay knows it was received.

## 6. Frontend Checkout Flow
Update the Pricing/Billing page:
- **User clicks "Subscribe"**: Call `/api/razorpay/create-subscription`.
- **Open Razorpay Checkout**:
  ```javascript
  const options = {
    key: process.env.NEXT_PUBLIC_RAZORPAY_KEY_ID, 
    subscription_id: response.subscriptionId,
    name: "ScalePods HR SaaS",
    description: "Subscription Upgrade",
    handler: function (response) {
      // Payment successful, verify on backend or wait for webhook
      toast.success("Subscription Activated!");
    }
  };
  const rzp = new window.Razorpay(options);
  rzp.open();
  ```
